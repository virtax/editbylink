# Guidelines

1. **Answer questions first**: Answer questions directly without editing code. Make edits only upon explicit request.
2. **Strict scope**: Do only what was explicitly requested. Propose other ideas in text first.
3. **Testing**: Always run `npm test` after code modifications.
4. **Concise code**: Keep generated code as concise and minimal as possible to fulfill the task.
5. **UI/UX Consistency**: Ensure strict visual and interactive consistency across all interface components:
   - **Unified Control Metrics**: All interactive elements (buttons, inputs, dropdowns) must share identical height, border-radius, vertical alignment, and padding standards.
   - **Disciplined Typography**: Maintain a unified font hierarchy with consistent sizing, font weights, and line heights across panes.
   - **Restrained Color System**: Use a curated token palette (CSS variables) with a minimal set of background, text, border, and accent colors across light and dark modes.
   - **Predictable States**: Apply uniform transition speeds, hover, focus, and active states across all controls.
